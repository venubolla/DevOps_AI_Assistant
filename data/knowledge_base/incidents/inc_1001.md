# INC-1001 — Payment Service Deployment Failure

## Incident Summary

Payment Service version v2.4.1 failed during production deployment.

## Impact

Customers experienced failed payment requests for approximately
12 minutes.

## Symptoms

The newly deployed pods entered CrashLoopBackOff.

## Root Cause

The deployment referenced an environment variable named
PAYMENT_DB_TIMEOUT which was not available in the production
configuration.

The application terminated during startup because the required
configuration value was missing.

## Resolution

The deployment was rolled back from v2.4.1 to v2.4.0.

The missing configuration was subsequently added to the production
secret configuration.

## Lessons Learned

Deployment validation should verify required environment variables
before production rollout.
